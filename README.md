# ContactManagerAPI

## Описание
**ContactManagerAPI** — это веб-приложение на базе Spring Boot для управления контактами. Приложение предоставляет REST API для выполнения операций с контактами, таких как создание, просмотр, обновление и удаление.

## Функционал
- **Создание контактов:** добавление нового контакта с именем, номером телефона и email.
- **Просмотр всех контактов:** получение списка всех сохраненных контактов через API.
- **Поиск контакта:** получение информации о контакте по номеру телефона.
- **Обновление контактов:** изменение информации о существующем контакте.
- **Удаление контактов:** удаление контакта по номеру телефона.

## Технологии
- **Язык программирования:** Java
- **Фреймворк:** Spring Boot
- **Валидация данных:** Jakarta Validation (Bean Validation)
- **Инструменты:** Lombok для генерации кода
- **Структура данных:** TreeMap для хранения контактов
- **Архитектура:** многослойная (Controller, Service, Model)

## Структура проекта
- **Контроллер (Controller):**
    - `ContactController` — обрабатывает HTTP-запросы и возвращает ответы в формате JSON.
- **Сервисный слой (Service):**
    - `ContactService` — интерфейс, определяющий бизнес-логику.
    - `ContactServiceImp` — реализация интерфейса с использованием коллекции `TreeMap`.
- **Модель (Model):**
    - `ContactModel` — класс, описывающий контакт с полями: имя, номер телефона и email. Включает валидацию данных.

## Пример работы API
### Создание нового контакта
**POST** `/contact`
```json
{
  "name": "John Doe",
  "number": "12345678901",
  "email": "john.doe@example.com"
}
```
Ответ: `200 OK`
```
Контакт создан
```

### Получение всех контактов
**GET** `/contact/all`
Ответ: `200 OK`
```json
[
  {
    "name": "John Doe",
    "number": "12345678901",
    "email": "john.doe@example.com"
  }
]
```

### Поиск контакта по номеру телефона
**GET** `/contact/{number}`
Ответ: `200 OK`
```json
{
  "name": "John Doe",
  "number": "12345678901",
  "email": "john.doe@example.com"
}
```

### Обновление информации о контакте
**PUT** `/contact/{number}`
```json
{
  "name": "John Updated",
  "number": "12345678901",
  "email": "john.updated@example.com"
}
```
Ответ: `200 OK`
```
Ваш контакт изменен
```

### Удаление контакта
**DELETE** `/contact/{number}`
Ответ: `200 OK`
```
Контакт с номером: 12345678901 удален
```

## Как запустить
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/aligarkh7/ContactManagerAPI.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd ContactManagerAPI
   ```
3. Соберите и запустите приложение:
   ```bash
   ./mvnw spring-boot:run
   ```
4. Приложение будет доступно по адресу: `http://localhost:8080`
